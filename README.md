# HandsInWords 🤟

HandsInWords is a senior Computer Engineering project developed to support communication for people with hearing disabilities using technology and Artificial Intelligence.

The application explores multiple approaches for Arabic Sign Language communication through a mobile application.

## Key Features

- Sign language gesture recognition and translation to text and speech
- Speech-to-sign communication using a 3D avatar
- Video calling functionality to support communication with interpreters
- Mobile application interface developed using Flutter

## Technologies

- Flutter
- Firebase
- Agora
- Machine Learning
- DeepMotion
- 3D Avatar Technology
